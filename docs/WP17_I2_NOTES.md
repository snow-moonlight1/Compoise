# WP17-I2：截图任务草稿校对

状态：纯内存草稿模型与校对组件已实现；文件选择器、真实 OCR、Store 导入属于 WP17-I3。

## 已交付

- `lib/import_preview/draft_model.dart` 接受 `wp17r2-draft/1`，保留图片顺序、失败图片、任务行、父子关系、日期原文、待确认原因和重复图片提示。
- `lib/import_preview/draft_preview.dart` 支持多图排序、逐图跳过、标题/完成态/父项编辑、拆分/合并、排除与恢复、目标板和象限选择。
- 日期文本只作为待校对原文保留；不把 OCR 推断直接写成截止日期或提醒。重复图片必须确认提示，不能自动去重。
- 只有有效标题、父项关系、待确认项、重复提示、目标板和象限都满足条件时才允许提交；取消、失败或未确认不会调用提交回调。

组件只接收调用方提供的缩略图和 OCR 草稿，不持久化原图、中间结果或编辑状态。I3 应把 `ImportSubmission` 映射到现有批量任务命令，并在整批提交前再次做 Store 校验。
