# 路线图与已知限制

这里记录方向和已知限制，不承诺具体日期。想参与某一项，请先开 issue 讨论。

## 已知限制

- Linux 还没有按时提醒，只能发送测试通知。
- 截图导入支持 PNG 和 JPG，Android 一次最多 10 张；识别模型第一次使用时需要联网下载。
- 截图识别出的任务默认选中，可修改文字或取消选择后一次导入。
- 没有账号和云同步，多台设备之间只能通过备份文件迁移。
- 安卓的提醒是否准时，受系统和厂商省电策略影响。

## 实验功能（默认不启用）

以下内容在代码里有原型，但不在正式版中开放：

- 多设备同步；
- 开发者模式；
- 托管的 AI 服务（不需要自己的 API 密钥）。

## 可能的方向

- Linux 按时提醒；
- 更多截图格式和更准确的版面识别；
- 更多语言的界面翻译。
