# 路线图与已知限制

这里记录方向和已知限制，不承诺具体日期。每个版本具体做什么、改哪里、怎样算完成，见[实施计划](implementation-plan.md)。想参与某一项，请先开 issue 讨论。

## 已知限制

- Linux 还没有按时提醒，只能发送测试通知。
- 截图导入支持 PNG 和 JPG，Android 一次最多 10 张；识别模型第一次使用时需要联网下载。
- 截图识别出的任务默认选中，可修改文字或取消选择后一次导入。
- 没有账号和云同步，多台设备之间只能通过备份文件迁移。
- 安卓的提醒是否准时，受系统和厂商省电策略影响。

## 实验功能（默认不启用）

以下内容在代码里有原型，但不在正式版中开放：

- 多设备同步；
- 开发者模式；
- 托管的 AI 服务（不需要自己的 API 密钥）。

## 以后再评估

- Android 桌面小部件；
- AI 流式输出；
- 更多截图格式和更准确的版面识别；
- 更多语言的界面翻译（文案迁移到 ARB 之后）；
- Windows ARM64、F-Droid、Flathub、winget 等分发渠道。

## 明确不做

- 账号体系、自建云服务和自建 AI 中转；
- 默认开启的联网功能；
- 团队协作和多人功能。
