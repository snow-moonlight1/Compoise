## 关键操作记录

以下流程用 widget 测试和合成数据操作，覆盖的用例在 `test/wp13_task_interaction_test.dart`：

1. 打开普通新建，初始只有一个带复选框的输入行。输入“买牛奶”并保存，得到一个没有子项的普通任务。
2. 在首行输入“写方案”，按输入法的下一项动作，出现第二个复选框并聚焦该行，同时显示可编辑父标题。父标题输入“新项目”，第二行输入“联调”，再按下一项形成空尾行。保存后只得到一个父任务，子项依次为“写方案”“联调”，空尾行未保存。
3. 在当前模式粘贴带空行的多行文本，按步骤创建一个父任务；切到“批量新建独立任务”再粘贴同样结构，保存为各自独立的任务。编辑中间光标拆行、中文/日文组合态确认和空尾行退格也由同一用例验证。
4. 打开含长备注和子项的详情，首屏先显示正文与子项，备注只显示两行摘要；点击摘要进入完整纯文本编辑，取消后原备注保留。打开“时间”，选明天日期后取消，回到原详情草稿，截止日期未改变。
5. 打开“更多”，真实标签组件显示已存标签。新增标签后，Store 中的标签在保存前不变；保存后包含新标签。草稿单元用例还验证取消恢复，以及并发写入的备注和标签得到保留。
6. 模拟持久化指针写入失败，录入文本仍保留且只有一条内存任务；解除故障后点重试，输入被清空、错误提示消失，任务没有重复创建。

## 验证边界

- 360 dp 和键盘占用视图为 widget 布局模拟；未运行 Android 设备或模拟器的实际输入法与录屏。
- 1100 dp 为桌面尺寸 widget 渲染；未在 Windows 实际应用窗口及 Linux 预览程序中手动检查。
- 412 dp、200% 字号和暗色主题按自动化布局用例验证；设备级视觉效果未验证。
