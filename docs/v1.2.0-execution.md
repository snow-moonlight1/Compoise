## 规模基准

`COMPOISE_BENCH=1 flutter test --no-pub test/benchmark/sync_scale_benchmark_test.dart`，沙箱 Linux、Flutter 3.32.8、JIT 测试运行器（比发行版慢），合成数据（平均每个任务 1.5 个子项，日程项为任务数的 1/5）：

| 任务数 | 子项数 | 启动加载 | 修改 → 提交 | 读取任务库 | 首次上传（不加密 / 加密） | 修改 → 记录 | 修改 → 一轮 | 从文件加入 | 任务库 JSON | 同步状态 JSON | 同步文件（不加密 / 加密） |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1000 | 1529 | 133 ms | 32.7 ms | 2 ms | 231 / 174 ms | 80 ms | 159 ms | 186 ms | 337 KB | 756 KB | 62 / 62 KB |
| 5000 | 7512 | 283 ms | 164.7 ms | 10 ms | 575 / 627 ms | 417 ms | 764 ms | 757 ms | 1687 KB | 3763 KB | 306 / 306 KB |
| 20000 | 30224 | 1224 ms | 713.3 ms | 61 ms | 2485 / 2521 ms | 1826 ms | 3457 ms | 2888 ms | 6748 KB | 15094 KB | 1221 / 1221 KB |

- **启动加载、修改到提交**是现有存储（模拟的 SharedPreferences，只含编码和校验，不含真实写盘）。
- **首次上传**：从空状态生成同步状态并压缩（/加密）。**修改 → 记录**：一次修改后只在本机记下修改（每次修改后几秒内运行）。**修改 → 一轮**：一次修改后完整一轮（无其他设备文件）。**从文件加入**：新设备解密、合并、生成完整任务库。
- 以上同步计算都在后台 isolate 运行，不阻塞界面。
- 同步文件经 gzip 后约为任务库 JSON 的 18%；加密只增加 28 字节。5k 条任务约 300 KB，暂不需要分片或增量上传。
- **存储引擎决策点**：5k 条时“修改到提交”在 JIT 测试运行器上超过 100 ms（约 165 ms，个别运行到 320 ms）。JIT 结果不能直接代表发行版，需要在 Windows/Android 发行版上复测（可用 `tool/os22_perf_bench.dart` 的方式）后再决定是否立项迁移 SQLite；这不影响同步本身。

## OneDrive：需要维护者注册应用

用户在方寸里点“连接 OneDrive”即可登录，不需要自己申请密钥；前提是维护者注册一次应用，拿到公开的“应用程序(客户端) ID”。客户端 ID 不是密钥，可以写进开源代码。

1. 用微软账户登录 [Microsoft Entra 管理中心](https://entra.microsoft.com)（或 Azure 门户 → Microsoft Entra ID）。如果提示没有可用的目录，按提示注册免费的 Azure 账户（可能需要手机和银行卡验证，不会扣费）。
2. 应用注册 → 新注册：
   - 名称：`Compoise`
   - 受支持的帐户类型：**仅个人 Microsoft 帐户**
   - 重定向 URI：平台选“公共客户端/本机(移动和桌面)”，填 `http://localhost`
3. 注册后进入“身份验证”：在“移动和桌面应用程序”下再添加一个重定向 URI `com.compoise.app://oauth`（Android 回到方寸用）。
4. “API 权限” → 添加权限 → Microsoft Graph → 委托的权限：勾选 `Files.ReadWrite.AppFolder` 和 `offline_access`（可删除默认的 `User.Read`）。
5. 把“概述”页的 **应用程序(客户端) ID** 发给开发者。

## 华为云空间

调研结论（华为开发者文档，2025）：

- **接口**：云空间服务（Drive Kit）有 REST 接口，可以只访问应用自己的数据目录（`applicationData`），权限是 `drive.appdata`。需要华为开发者实名认证、在 AppGallery Connect 创建项目和应用、开通云空间服务 API、配置回调地址；可能还需要申请权限审核。
- **登录**：华为帐号支持 PKCE（不需要密钥）换取访问令牌，但访问令牌 1 小时过期，而**刷新令牌必须带应用密钥（client_secret）**。开源客户端无法保密这个密钥。
- **会员限制**：华为文档说明，用户升级到“全新云空间”服务模式后，仅会员服务支持使用云盘。HarmonyOS 5 及以后的新机型默认是全新云空间，免费用户可能无法让第三方应用使用云盘。
- **平台**：方寸的 Android 版不能直接运行在纯血鸿蒙（HarmonyOS NEXT / 5）上；Notein 等能用华为云的应用都有原生鸿蒙版。Drive Kit 的 Android SDK 自 2023 年 2 月后没有更新。

可选方案：

| 方案 | 优点 | 问题 |
| --- | --- | --- |
| A. 把应用密钥写进客户端 | Android、Windows、Linux 都能用 | 开源后任何人都能看到密钥并冒用方寸的身份；可能违反华为的开发者协议。不推荐 |
| B. 只在 Android 上用 HMS Core SDK | 不需要在客户端放密钥 | 只支持装有 HMS Core 的手机；引入闭源 SDK；电脑上不能用；SDK 多年未更新 |
| C. 不用刷新令牌 | 不需要密钥 | 每小时要重新登录一次，不可用 |
| D. v1.2.0 先不做华为云 | 不拖延发布 | 华为用户先用 OneDrive 或 WebDAV（如坚果云） |

**维护者决定（2026-10-19）：v1.2.0 采用 D**，发布 OneDrive 和 WebDAV；之后如果华为用户需求明确，再评估 B，并先用真实的华为帐号确认免费用户能否使用。
