- **WP16**：基于 WP14 的今天页实现完成庆祝。只在今天页的未完成任务从非空变为全完成时触发，考虑每日去重、减少动态效果与关闭选项；不改计划日和 Planner 数据契约。
- **WP28-R**：只核对 Windows 旧版与当前构建的应用数据目录身份、升级路径和可复现证据，给出保留目录或显式迁移的建议；先不改存储实现，也不宣布正式发行。

WP17 暂不作为实现包派发。若仍需评估手动迁移，可单独做一次小范围 WP17-P 探针：只用合成待办验证分享格式；如果拿不到可用文本，就停止小米专属适配。WP19 可重新拆解；WP18、WP29 暂缓到核心任务流稳定后再评估。
