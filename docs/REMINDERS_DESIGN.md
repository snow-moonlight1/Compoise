# 提醒设计

提醒以任务或子任务的提醒时间为依据。截止日期用于紧急性判断，提醒时间单独决定系统何时尝试通知。编辑、完成或删除任务时，提醒服务会随 Store 的最新状态调整对应通知。

## 调度与状态

- ReminderService 负责权限检查、计划通知、取消通知、启动恢复和失败记录。
- 提醒状态以稳定任务 ID 关联任务和子任务；通知点击由应用入口解析并交给对应页面。
- Android 支持通知权限、闹钟调度和开机后的提醒恢复。可用调度精度取决于 Android 版本、权限和设备省电策略。
- Windows 使用本地通知，并结合桌面托盘和应用生命周期管理提醒服务。
- Linux 预览版目前没有系统提醒通知；任务上的提醒时间仍可编辑，但不会触发通知。
- 已完成、删除或提醒时间变更的任务会清理过期调度状态。暂时失败的调度保留状态供后续重试或提示。

## 用户可见限制

系统可能延迟或阻止后台通知。用户需要在操作系统设置中允许通知，并按设备提示配置后台运行或闹钟权限。强制停止、厂商省电限制、权限撤回和设备重启时机都可能影响送达；应用不能保证每条提醒都准时到达。

## 相关实现

- lib/services/reminder_service.dart：提醒调度、权限、持久化账本和恢复逻辑。
- lib/storage.dart：任务改动与提醒状态协调。
- lib/screens/settings_screen.dart：权限说明、测试提醒和问题提示。
- test/reminder_service_test.dart 与 test/os12_date_reminder_test.dart：提醒规则和用户流程回归。
