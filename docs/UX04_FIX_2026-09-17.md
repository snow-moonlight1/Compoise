## 本机字体核对（开发机，非渲染验收）

`System.Drawing.Text.InstalledFontCollection`：有 Microsoft YaHei UI、Noto Sans SC、Consolas、Georgia、Yu Gothic；无 Microsoft YaHei、SimSun、SimHei。黑体候选因此以 YaHei UI 为先，不把未安装的 SimHei 写成唯一修复。

## 改动

- 新增 `lib/ui/font_policy.dart`：Windows / Android 分列字体。Windows 系统与等宽都带 YaHei UI CJK 回退；黑体选项主字体为 Microsoft YaHei UI。Android 不写 Windows 字体名。
- `theme.dart` 用 `TextTheme.apply` 真正套上 family/fallback；正文 w400、标题 w600；选区只改颜色，不改字形。
- 设置预览含中英日混合样句、标题/正文两档字重；等宽选项显示“拉丁等宽、CJK 回退”说明。不改用户已存的 fontFamily。
- 去掉界面里用 w800 冒充中文粗体的标题。
