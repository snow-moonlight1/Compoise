### 1.2 已确认的来源与根因

| 项目 | 当前证据（均相对 `matrixflow-native/`） | 判断 |
|---|---|---|
| 命令台 | 旧计划 WP26-A 明确要求；`lib/shortcuts.dart`、`widgets/command_palette.dart`、`screens/matrix_screen.dart::_openCommandPalette/_header` | 规划主动增加了该交互，不能称为执行者凭空做错；双端固定入口与手机键帽进一步放大问题 |
| 顶部统计 | 旧计划 WP27-A 明确要求主页/聚焦/已完成页展示；`matrix_screen.dart` 无条件插入 `TaskStatsBar` | 规划本身需要撤销。色块和局部统计状态让用户误认为是全局看板控制 |
| “当前看板”点击无反应 | `task_stats_bar.dart` 的 `_allBoards` 仅切换计算范围，不切换任务列表；空板两种结果都可能为 0 | 代码确有点击回调，不能虚报为完全无回调；交互含义不清是真问题，按要求删除而非修饰说明 |
| 归档百分比 | `completed_screen.dart::_buildHeader` 用整个范围的 `store.tasks` 算完成率，下面又有 `_buildTrendsCard` | 百分比是范围内全部父任务的完成比例，混在已完成列表容易误解；需要去除 |
| 横滑筛选 | `search_screen.dart::_buildFilterChips` 用横向 `SingleChildScrollView` + 一长排 Chip | 核心条件超出视野；桌面可达性不足，不能仅加滚动条交差 |
| 字体 | `theme.dart` 等宽候选仅 `Consolas/Roboto Mono/Courier New/monospace`，无显式 CJK 候选 | 与用户切黑体改善相符；尚未验证每个异常字实际使用的字体，不能断言某字体缺失或系统损坏 |
| 父子缩进 | `task_card.dart` 子项放在父任务复选框右侧的正文 Column 内，又加 left padding 和子项 48dp 框列 | 只把子项 `left: 4` 改零不够；必须把父行、子行提升到同一行布局坐标系 |
| 删除线 | `widgets/anim.dart::StrikeThrough` 是 StatelessWidget，直接切换 `TextDecoration.lineThrough` | 现有逐行静态划线不是动画；完成状态正确也不能满足 U08 |
| 聚焦 | `matrix_screen.dart` 用条件直接替换 `_grid` / `QuadrantFocusView`；后者是静态 Column | 尚无连续几何过渡；象限拖入时的 180ms 背景色动画不能算聚焦动画 |
| 入口密度 | `_header` 有 7 个常驻动作，统一缩为 34dp + shrinkWrap | 用缩小触摸目标应付溢出是错误方向；需要重新分配入口 |

这里只对可核实的规划/实现归因，不推断是哪一个历史 Agent 或哪一轮对话个人提出的。用户本次明确要求覆盖旧规划，无须再要求用户为删除这些功能确认一次。

## 4. 统一交互规格（后续 Agent 不再自由发挥）

### 4.1 Android 主界面与操作去向

常态示意：

```text
[看板名称 ▾]                       （无七按钮工具条）
紧急且重要       │ 不紧急但重要
父任务           │
子任务（同列）   │
─────────────────┼────────────────────
紧急但不重要     │ 不紧急也不重要
                 │
[搜索]               [＋添加任务] [更多]
                 系统手势安全区
```

- 底部是三个**动作**，不是暗示三个页面常驻的 Tab：搜索、添加任务、更多。文字标签可见，至少 48dp 热区；默认约 56–64dp 高，随大字和安全区自然增高。保留当前首页十字矩阵，移除旧统计条及其空白。
- 顶部保留看板名称/下拉。手机点标题打开底部看板选择器；“更多”也有“切换看板”，供拇指操作。这是可达性替代，不产生第二套看板状态。
- 更多打开底部纵向操作面板：`切换看板`、`已完成`、`视图：矩阵/列表`、`显示已完成任务`开关、`选择任务`、`设置`。选中状态明确，行高至少 48dp，面板可纵向滚动。
- 看板选择器列出真实看板名称，当前项带勾；管理动作单独分组为新建/重命名/清空此看板/删除此看板。清空/删除继续确认板名和影响范围；删除最后一个看板的既有约束保留。
- 多选后底部替换为已有上下文操作条：数量、现有单项编辑/多项分组、退出；窄屏使用纵向“操作”菜单容纳现有动作，不加入尚未实现的 WP10 批量拖动。完成方框继续表示完成，不能改成选中标记。
- 聚焦时上方有明确“返回四象限”动作；其他三象限收在主内容底部，位于全局操作条上方。不能盖住列表最后一项。
- 搜索、设置、归档是独立页面；进入这些页面后不保留首页的全局三按钮条，使用各页面自己的返回/操作区，避免两层底栏。

### 4.2 Windows 主界面

```text
[看板名称 ▾]          [搜索] [＋添加任务] [更多]
┌────────────────四象限内容─────────────────┐
│                       │                  │
│                       │                  │
└──────────────────────────────────────────┘
打开任务时，空间足够才显示右侧详情；否则显示独立编辑面板。
```

- 顶部仅保留看板选择及搜索、新建、更多三个动作；合适宽度用文字+图标，窄窗可收成有 tooltip 的图标，不能缩小至难点的区域。已完成、视图、显示完成、选择、设置归入更多。
- 不常驻左侧 320dp 新建面板。点新建/Ctrl+N 时打开可关闭的输入面板或弹窗；已有输入草稿不因再次调用新建而重置。
- 主编辑上下文一次只活动一个：任务详情有未保存草稿时先走既有保护再换新建；取消保护则保留原详情。不要在左右同时塞满新建与详情挤压矩阵。
- 右侧详情宽度约 340–360dp，只在扣除面板/间隔后主内容仍有至少约 560dp 时并排；否则切覆盖式/独立编辑面板。用实际可用宽度决定，不能只看总窗口 `>=900` 就硬塞。
- 鼠标点击、右键、滚轮、Tab/Shift+Tab、Enter/Space、Esc 均能使用。Windows 小窗仍可使用快捷键；触控 Windows 也须能点击所有功能。
- Android 横屏/平板不因为宽度大就启用桌面命令、托盘设置或 Ctrl 提示。可复用详情内容，平台壳层与业务逻辑分离。

### 4.3 所有旧入口的唯一去向

### 4.4 统计与归档的边界

- `TaskStatsBar` 的完整 UI 退出产品；待办数、逾期数、总子项进度条不转移成另一条常驻摘要。
- 设置→显示增加 `showCompletionRate`，默认 **false**；旧安装、旧备份缺字段同样 false。文案：“显示总体完成率”；说明：“在更多面板中显示全部看板的任务完成比例”。
- 开启后仅在**首页更多面板底部**显示一段无按钮样式的次要文字：`全部看板：已完成 3/10 项（30%）`。这是本轮为可选统计确定的展示位置；不占首页常态、不占聚焦内容、不出现在搜索/归档。
- 分子＝全部看板当前仍存在且已完成的父任务数；分母＝全部现存父任务数。子项不重复计数；隐藏完成、搜索条件、当前象限不影响该值。删除会改变分母，不能称“历史累计/今日效率”。零任务显示“全部看板：暂无任务”，不显示 0%/100% 的误导进度。
- 已完成页只做完成任务的查找/恢复/删除：标题“已完成”，范围选择、完成时间/来源板、任务列表。可显示清晰的 `列表中 12 项` 表示当前结果数；没有总体完成率、待办数或七日趋势卡。
- 移除趋势卡属于本轮“归档回到列表”的设计决定；保留 `completedAt`、排序、旧完成时间未知的处理及备份字段，不为删 UI 删除数据历史。父任务内的“子任务 1/3”用于操作与展开，仍保留；它不同于总体完成率。

### 4.5 搜索筛选

- 保留 `task_query.dart` 的四维口径：范围（当前/全部板）、象限（全部/四个全名）、状态（全部/未完成/已完成）、日期（全部/今天/本周/本月/逾期/无日期）。本包不新增语法、排序或日期算法。
- Android：上方搜索输入框+返回；下面最多是能换行的已应用条件摘要和结果数。底部固定 `筛选（n）`、`清除筛选`，手指无需去顶端横滑。点筛选先收软键盘，打开约 70% 高的底部面板，可向上扩展；里面四组纵向单选列表或自适应 Wrap，禁止横向滚动。底部固定“重置”“应用”，内容独立纵滚。
- Windows：搜索框右侧一个“筛选（n）”按钮，打开锚定弹出面板；窄窗用有最大宽高约束的模态对话框。内部同一四组表单纵向滚动，有滚动条、键盘焦点、应用/取消/重置。普通滚轮就能到最后一个日期选项。
- 筛选使用临时 draft：打开时复制已应用条件；修改不立即影响后台列表；“应用”提交整份条件；Esc/返回/遮罩关闭丢弃未应用 draft；“重置”只重置 draft；列表上的“清除筛选”立即恢复默认条件但保留关键词。
- 默认：当前板、所有象限、所有状态、所有日期。`n` 为偏离这四项默认值的维度数量，不按 Chip 数累加；全部板也算一个非默认维度。
- 条件摘要允许两行及以上自然换行，不横向裁切、不把未选项全部铺在顶端。空关键词+默认条件仍显示现有任务；空结果显示关键词/范围并给出清除筛选、清空关键词的动作。
- 应用筛选后不自动重弹软键盘，保留关键词和搜索页滚动状态；回到输入框才弹键盘。切换宽窄布局不丢 draft。从搜索打开子项仍定位原父任务及命中子项。
- 归档只有范围筛选，复用相同范围选择内容即可，不显示无意义的“完成/未完成”过滤器。

### 4.6 任务行、字体与基本尺寸

| 项目 | 矩阵常态 | 聚焦/全宽列表/详情 |
|---|---|---|
| 父/子正文横坐标 | 相同，子项不嵌进父正文 Column | 子项可向内 16dp；只保留当前真实父子两层 |
| 父/子复选框 | 视觉建议 20–22 / 16–18dp；二者热区都 ≥48×48dp（Android） | 同样区分视觉大小，使用正常列表间距 |
| 标题 | 父约 16sp / 500；子约 14sp / 400；随系统字号缩放 | 可增加可读空间，不把字体放大当作缩进替代 |
| 行高 | 最小 48dp，长文本自然增高，框对齐文字首行 | 多行、备注、日期有足够空间 |
| 子项入口 | 父行“子任务 1/3”+展开状态；移除大块内嵌添加框 | 详情中的“添加子项”保留并可直接编辑 |
| 同一父组 | 展开子项紧跟父行；组间 8–12dp 空隙 | 明确层级；无子任务的任务不占展开入口 |

- 同列指文字起点相同、复选框中心线相同；视觉小框居中在同样宽的框列里。不用透明左边距伪装“无缩进”。换行后不侵入框列。
- 子项可点文字打开父详情并定位该子项；点复选框仅完成；点展开仅展开。矩阵中不再给每个子项加新的编辑图标。父子关系除字号外，还由组间距与读屏标签表达。
- 不改数据模型为无限层级。完整象限名称不缩写成 Q1/Q2；小屏允许换行，减少无必要的计数/装饰占位。象限计数继续只是当前可见任务数，不是总体统计。
- 颜色沿用现有主题与四象限色。间距基准 4/8/12/16/24dp；普通文字优先 `onSurface/onSurfaceVariant`，边界 `outlineVariant`。选中、完成、错误、不可用各有语义，不能只靠降低透明度区分。
- 本轮修复现有字体四选项，不新增三套装饰字体。系统/黑体用于一般界面；衬线/等宽为用户主动选择，默认仍 system。Windows 中文需显式 CJK 回退；不把某个系统未必存在的西文字体名当完整中文字体。

### 4.7 动效必须表达状态变化

| 动效 | 默认目标 | 验收重点 |
|---|---|---|
| 完成划线 | 约 220ms，easeOut；按可见文字行从起点到终点画线 | 多行不是横穿整个矩形的一条线；取消完成反向撤线，快速连点可打断 |
| 完成后隐藏 | 划线后约 100–140ms 收拢，合计约 320–360ms | 业务立即保存，UI 退场稍后；不等待整段动画才持久化 |
| 矩阵→聚焦 | 约 320ms，easeInOutCubic | 所选四象限之一从原位置扩大，其余三个同时缩小并移向下方 |
| 聚焦→矩阵/切换 | 返回约 260–320ms；切换约 280–320ms | 能看出来源和目标；返回模式、滚动和展开状态保留 |
| 减少动画 | 系统请求或应用 `reduceMotion=true` 时立即到终态 | 不等待隐藏计时；语义与可操作性不变；无排队播放 |

具体时长是首轮实施目标，可据双端录屏小幅调整并记录理由；不得把几何变化改成纯淡入淡出、整屏缩放，或把静态删除线声称为已完成动画。

## 5. 技术边界与易错点

### 5.1 共享业务，分别适配输入

建议新增小型 `lib/ui/platform_ui_policy.dart`（名称可随项目风格调整），集中提供 `isWindows`、`isTouchLayout`、快捷提示策略和可用布局宽度判断。平台参数可注入测试；不要让每个控件散落 `Platform.is...`，也不要只用窗口宽度推断设备。

新导航、弹层和列表仍调用现有 Store/任务服务。现有草稿保护、提醒、持久化错误、撤销代次、跨任务编辑保护不能在“拆组件”时复制成第二套实现。

`showCompletionRate`（UX02）和 `reduceMotion`（UX06）均为 AppSettings 布尔字段，默认 false。必须同步 `models.dart` 构造/fromJson/toJson/copy 路径、`storage.dart` 默认/加载/更新/重置策略、`data_migrations.dart` 导入白名单、设置页及 en/zh/ja。沿现有 v2 加可选字段；v1 降级导出剥离，旧 v1/v2 缺字段均正确兜底。不改变四个核心存储键。不要重置用户显式字体、hideCompleted、提醒配置或 BYOK。

### 5.2 划线、完成和退场的关系

- 在 `anim.dart` 或独立 `animated_task_title.dart` 引入明确文字参数的组件（text/style/maxLines/overflow/locale/direction/textScaler/completed），避免现有“任意 Widget 包一层再判断是不是 Text”的不完整布局契约。
- 采用共享文本排版结果绘制标题及逐行线段，或与 RenderParagraph 等价且经过测试的度量方案；不能按字符数或平均字宽计算线长。保留字重、字体回退、字号缩放、换行/省略、混合文字和读屏语义。
- 参考 Flutter [LineMetrics](https://api.flutter.dev/flutter/dart-ui/LineMetrics-class.html) 与 [TextPainter.getBoxesForSelection](https://api.flutter.dev/flutter/painting/TextPainter/getBoxesForSelection.html)：行度量只描述整行，双向文字可能产生多个可视片段，换行可能是零宽盒。线段只覆盖实际可见字形/省略后的显示区域，不跨空白或备注/日期。
- 初次加载已完成任务直接显示终态；仅 mounted 的完成状态变化播放。Widget key 用稳定 taskId/subtaskId，不能用 completed 值让组件每次重新初始化。进入/退出聚焦不能重播所有任务的入场/完成动画。
- 所有完成入口（父/子复选框、滑动、右键、搜索命中、父子自动联动、撤销）调用统一业务语义，再由状态变化驱动画面。特别核对搜索中直接修改 `task/subtask.completed` 后 `updateTask` 的路径，避免与父子/时间戳规则不一致。
- `hideCompleted=true` 时，不能延迟写 Store 以等动画。由列表层保存即将退场项的短期**展示快照/稳定位置**，真实任务状态已更新。列表查询和统计读取真实数据，退场项不重复参与计数或可交互列表。
- 快照只属于当前 board/view 生命周期；撤销/反选取消对应退场；删除、清空、导入、切板、页面销毁立即清理；计时回调绝不写回任务。父任务因最后子项完成而消失时，整父组退场，只保留一份画面；完成后立即杀进程仍应正确保存。
- 搜索“未完成”过滤、归档“恢复”过滤也会使项消失，采用相同退场协调或明确轻量退场，不能在这些入口把静态瞬移遗漏掉。不动画仍可正确操作。
- 应用 `reduceMotion` 与系统关闭动画取逻辑 OR；自定义动画显式读取该策略，既有 `StaggerIn` 也必须遵守。Flutter 官方 [disableAnimations](https://api.flutter.dev/flutter/widgets/MediaQueryData/disableAnimations.html) 是平台减少动画信号；用测试注入只验证本应用策略，不能据此声称系统设置实测通过。

### 5.3 聚焦的几何与状态

- 建议新增 `widgets/quadrant_transition_layout.dart`，让四个象限在同一有界 Stack/自定义布局中持有稳定身份。每个象限有矩阵 rect 与聚焦目标 rect，用同一动画进度插值；不得只用 `AnimatedSwitcher` 在两个互不相关树之间淡入淡出。
- 布局空间只含矩阵内容区，排除顶部、安全区、底部操作条和右侧详情；Windows 缩放/打开详情后重新算目标 rect，不拿屏幕绝对坐标。
- 常态四个矩形等分内容；聚焦目标为上部主区+下方三个卡片槽，顺序固定原象限编号去掉所选。选中象限位于上层，其余可沿各自插值路径收拢；标题与色点保留可追踪身份。
- 下方卡片最小热区 48dp、完整名称换行；正常三列，高文字缩放/极窄可改成三行。高度由实际排版计算，不硬编码 60dp 导致遮字；主区不足时允许外层纵滚而不是压缩所有触摸目标。
- 内容从矩阵“无缩进”过渡到聚焦“层级”可在展开后半段重排或短暂交叉淡化，但象限容器本身必须连续扩大。裁切内容防飞出边界，不对文字做明显拉伸变形。
- 维护明确状态：matrix / entering(q) / focused(q) / switching(a,b) / exiting(q)，以及来源 viewMode。动画中收到返回或另一个聚焦目标，从当前几何位置重定向，不重置到首帧、不堆积路由。
- 每个 board+quadrant 的滚动位置和展开状态继续保存；矩阵与聚焦可分开记 offset；切板清理失效 taskId，重新进入不得复活已删项。一个 ScrollController 不可同时挂在两棵可见树。
- 过渡中可短暂屏蔽任务行拖拽/点击，标题切换和返回仍可处理；隐藏/离场树排除 hit test、focus 和 semantics，不重复播报/重复提交。静止后恢复拖动到下方象限卡片。
- 列表模式进入聚焦时，从当前分节的可见位置过渡；非可见节不强求穿过长列表飞入，可用短位移/淡化辅助，退出回列表原滚动位置。不能退出后悄悄变矩阵。用户要求的完整四块几何效果以矩阵入口为强制验收。
