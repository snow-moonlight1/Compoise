## 改动

### 1. 完成划线改为可中断的逐行动画

- 新增 `lib/widgets/animated_task_title.dart`：`AnimatedStrikeThroughText` + `StrikeThroughPainter`。
- 线段来自 `TextPainter.getBoxesForSelection`（同一个 `TextPainter` 参数与渲染的 `Text` 一致：style、maxLines、ellipsis、locale、textScaler、textWidthBasis），按实际可见字形/省略后的显示区域绘制；不按字符数或平均字宽估算，不跨整行矩形。
- 220ms、easeOut；`completed` 变化时 `forward/reverse`，快速连点只重定向同一个 controller，不排队。首帧为终态：初次加载已完成任务不补播（验收「进入/退出聚焦不重播」）。
- 替换 `task_card.dart` 父/子标题与 `search_screen.dart` 结果标题的旧 `StrikeThrough`（旧组件保留给归档，归档项恒为终态）。
- 计数与统计仍读真实数据；`widget.key` 用 taskId/subtaskId，不随 completed 重建。

### 2. reduceMotion 全链路

- `AppSettings.reduceMotion`（默认 false）：`models.dart` 构造/fromJson/toJson（v2 写入，v1 降级剥离，旧备份缺值兜底 false）；`data_migrations.dart` 导入仍走 `AppSettings.fromJson` 白名单。
- 新增 `lib/ui/motion_policy.dart`：`reduceMotionOf`（可监听）/ `reduceMotionNow`（initState 与回调安全用）+ 时长常量（划线 220ms、退场保持 220ms、收拢 120ms、入场步进 45ms）。取值 = **应用设置 OR 系统 `MediaQuery.disableAnimations`**。
- 设置页「显示」新增开关（key `reduce-motion-toggle`），en/zh/ja 三语齐备。
- `StaggerIn` 改为在 `didChangeDependencies` 判断：减少动画时立即终态，不再排队延迟入场。`TaskCard` 的 `Dismissible` 时长同样遵守。
- 减少动画时不保留退场快照，UI 不等隐藏计时（完成照旧立即持久化）。

### 3. hideCompleted 安全退场

- 新增 `lib/widgets/task_exit.dart`：`ExitRetention<T>`（展示快照缓存）+ `ExitingRow`（保持 220ms 后 120ms 收拢淡出，`IgnorePointer` + `ExcludeSemantics`，排除 hit test/焦点/读屏）。
- `ExitingRow` **常驻树中且结构恒定**，只翻转 `exiting` 标志：若改成「退场时才包一层」，行子树会被重新 inflate，`StaggerIn` 会重播入场淡入（已用反例验证：条件包裹时该行 opacity 为 0.0，恒定结构时为 1.0）。退场行因此保留原有元素与划线动画，不会闪一下再消失。
- 接线：`quadrant_pane.dart`（矩阵与聚焦）、`task_list_view.dart`（按象限各一份）、`search_screen.dart`、`completed_screen.dart`（后两者为计划允许的轻量退场）。
- 只保存**展示快照**：计时回调仅 `setState` 移除快照，绝不写回任务；真实完成状态在点击瞬间已由 Store 落盘（用例直接读 `matrixflow-tasks` 校验）。
- 失效条件：任务被删除/清板/导入 → `keepIfMissing` 为 false，立即消失；切板/代次变化/页面销毁 → 清空并取消计时器；撤销或反选使任务重新出现 → 取消待定退场。
- 搜索把关键词与筛选条件计入 epoch：因输入/改筛选而消失的行立即消失，因自身状态变化而消失的行才播退场。

### 4. 完成入口只写一次业务

- `_checkColumn` 的 `Checkbox` 包 `IgnorePointer`，48dp `GestureDetector` 独占点击；父行 `InkWell` 不再覆盖复选框列（点框只完成，点正文才编辑/选择）。一次点击 = 一次业务写入、一次提醒取消、一次时间戳更新。
- 已核对搜索内直接改 `task/subtask.completed` 后 `updateTask` 的路径：`updateTask` 会补/清 `completedAt` 并处理 `autoCompleteParent`，与父子/时间戳规则一致。
