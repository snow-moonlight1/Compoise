## 输入与层级

1. 普通新建默认一行可勾选任务和输入光标。输入一项即可保存，不要求先填父标题或属性。
2. 在任务行确认换行后，显示下一复选框并聚焦下一行；进入多行草稿时出现可点击修改的父任务标题。所有输入行保留为步骤，第一行不能被吞掉或偷偷当成父标题。
3. 新建保存时只有一个非空步骤且未显式命名分组，保存普通任务；至少两个非空步骤，保存一个父任务及其子任务。父标题未填写时用第一项生成简短可编辑名称，并在保存前显示该结果；不调用 AI、不强制命名。空白尾行不落库。
4. 删除空白尾行可回到单项草稿；显式父标题、有属性的步骤和已有父子任务不得因只剩一项而自动降级丢字段。已存任务按原结构编辑，不按旧标题里的换行重新拆分。
5. 现有普通输入逐行创建独立任务的能力保留在“批量新建”入口；明确提示当前是“一个任务的多个步骤”还是“多条独立任务”。多行粘贴遵循当前模式，保存前可检查结果；不自动请求 AI。
6. 中文/日文输入法确认候选时不得新增任务行或保存。处理中间光标拆行、选区替换、连续换行、空行退格与焦点回退；备注和父标题中的换行仍是文本换行。桌面保留明确的保存快捷键及 Tab 顺序。

## 内容优先、属性按需展开

| 位置 | 显示与操作 |
|---|---|
| 内容区 | 单项正文，或父标题紧接子任务清单；列表内勾选、编辑、增加下一项保持直接可达 |
| 操作区 | 紧凑的“时间”“更多”和“保存”；软键盘打开后仍可到达保存与下一行 |
| 时间面板 | 分别标明截止日期与提醒时间；今天、明天、自定义等预设只出现在这里；支持确定、取消、清除。仅设置提醒不得偷偷改变截止日期，反之亦然 |
| 已设属性摘要 | 有值时显示简短可点的日期、提醒、象限、标签等摘要；无值时不铺开所有候选 |
| 更多属性 | 象限选择、长期任务、添加备注、标签、AI 操作及删除等次级动作；四象限含义及既有自动紧急性规则保持清楚 |
| 备注 | 空备注为轻量入口；非空显示有限行摘要，点击后编辑完整纯文本。父子备注可查看、编辑、清除和搜索，收起不截断数据 |

子任务的日期、提醒和备注通过该行的详情入口编辑。二级面板关闭返回原草稿和焦点；取消二级修改不影响主草稿。删除放在次级菜单并沿用明确的删除确认。

使用现有主题、字体和动效策略，间距优先 8/12/16/24 dp、触控目标至少 48 dp。层级由内容顺序、留白与摘要体现；避免继续堆叠大边框。加载、空值、保存失败、提醒权限失败须有可理解的反馈；不能让失败消耗草稿。保持明暗主题、焦点可见性与屏幕阅读器标签。

## 验收

- 单行直接创建；两行及多行形成一个有步骤的父任务；父标题可改；空行不生成任务。批量独立任务仍可创建，AI 输入/分组/取消路径可用。
- 新建、矩阵详情、搜索进入详情和子任务编辑遵循同一层级。修改期间切换任务、关闭、返回、保存失败及迟到 AI 响应不串任务、不覆盖新数据。
- 单任务无备注、长备注、多子项、已完成子项、有日期/提醒/标签的合成数据均验证；旧多行标题和旧父子备注原样往返，重启及备份导入导出不丢失。
- Android 360/412 dp、键盘展开、200% 字号、明暗主题下无溢出，任务内容与保存入口优先可达。Windows 窄/宽窗和 Linux 预览完成相应键盘与布局检查；未测设备明确记录。
- 补充行为回归测试；运行贡献指南要求的 analyze 和默认测试。交付改动前后截图、逐行录入/修改父标题/展开时间/返回草稿的短录屏或操作记录，截图只用合成任务。
