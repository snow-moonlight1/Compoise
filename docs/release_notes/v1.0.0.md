# MatrixFlow AI v1.0.0 — 官方开源首发 / Official Open Source Release

MatrixFlow AI 是基于**艾森豪威尔四象限法则**打造的现代化、本地优先（Local-First）且内置 AI 智能助手的全平台任务管理工具。一套精炼的 Flutter 架构驱动 **Android APK** 与 **Windows 原生桌面端**，无 WebView 性能包袱，提供丝滑流畅的操作体验与绝对的个人隐私保护。

---

## 🌟 核心亮点 / Key Highlights

1. **纯本地离线与绝对隐私（100% Local-First & Zero Telemetry）**
   - 所有任务、子项、备注与统计数据均保存在设备本地；
   - 零中央服务器、零后台追踪、零广告埋点 SDK，完全离线无障碍运行。

2. **BYOK 用户自带密钥与多模型智能助手（Bring Your Own Key）**
   - 支持主流 AI 服务商预设：DeepSeek 官方、火山引擎、阿里云百炼，以及任意 OpenAI 兼容端点和 Anthropic Messages 协议；
   - 支持动态模型拉取与思考模式（Thinking Mode / Reasoner）；
   - 一键智能四象限分类、长任务拆解（3–5 项子任务）与同类任务智能合并，端到端直连官方 API，绝无第三方代理中转。

3. **四象限十字矩阵与沉浸交互**
   - 无框十字极简矩阵，首行对齐复选框与多行逐行删除线；
   - 支持长按拖拽跨象限移动与智能置顶；
   - 支持单象限聚焦模式（Quadrant Focus View）与宫格/列表双视图自由切换。

4. **跨端定时提醒与后台保活**
   - **Android**：原生通知与准时提醒（规范使用 `SCHEDULE_EXACT_ALARM`，杜绝 `USE_EXACT_ALARM` 违规），设备重启后自动恢复排期；
   - **Windows**：WinRT Toast 系统横幅通知，集成系统托盘（System Tray）常驻与最小化保活，点击通知一键唤起主窗口与深层任务跳转。

5. **桌面效率套件与人性化细节**
   - 全局命令面板（Ctrl+K / ⌘K）支持拼音与模糊搜索，快速跳转任务与执行操作；
   - 任务滑动操作与 5 秒浮动撤销（Undo）；
   - 7 日完成趋势直方图与已完成历史看板；
   - 新手 5 步响应式引导教程，随时在帮助中重新回顾。

```bash
git clone https://github.com/matrixflow/matrixflow.git
cd matrixflow/matrixflow-native

# 运行自动化测试回归（255 项测试）
flutter test --no-pub
flutter analyze --no-pub

powershell -ExecutionPolicy Bypass -File ..\scripts\build_release.ps1
```
