# MatrixFlow AI v1.0.0 发行说明草稿

**尚未发行。** 本仓库没有公开 remote、tag、正式 Android 签名或托管下载页。此文件仅供持有人准备发行时复核；不能作为下载公告。当前 `pubspec.yaml` 版本为 `1.0.0+1`，发行脚本规划的文件名含 `v1.0.0+1`，最终名称以实际签名构建为准。

MatrixFlow AI 的持续开发客户端是 Flutter Android 与 Windows。提供四象限任务、看板、子任务、提醒、搜索、已完成列表及可选的自带密钥 AI 分类、分组和拆解。Windows 还提供托盘、通知和快捷键。

普通任务数据留在本机应用数据里，未作应用层加密。使用 AI 时，相关任务文本会发往用户配置的模型端点；自定义端点可能是代理或 HTTP。密钥在系统保护存储中。默认明文 JSON 备份省略密钥，明确选择包含时文件会含明文密钥。v1 可读，v2 是默认导出格式；降级到 v1 会丢失部分字段。详情见 [隐私说明](../PRIVACY_POLICY.md) 和 [备份格式](../BACKUP_FORMAT.md)。

本地固定 Flutter 3.32.8 / Dart 3.8.1 可以运行测试并构建 Android debug APK 和 Windows Release 可执行程序。Windows 构建尚未 Authenticode 签名，Android 正式包必须提供持有人的签名材料。Android 实机交互、通知、覆盖升级与远端 CI 仍待验收，不能以本地 mock 或构建成功代替。发行门槛见 [OS26 记录](../OS26_NOTES.md) 与 [开发指南](../DEVELOPMENT.md)。

正式发行前须填写真实托管、问题反馈和安全联系方式，完成签名、校验和、双端设备验收，再更新此文的下载与版本信息。
