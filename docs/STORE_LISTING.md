## 3. 权限合法合规说明（商店审核专用答辩材料）

各大主流商店（尤其是 Google Play、小米、华为）在审核待办应用时会严格审查通知与自启权限。在商店后台权限声明处，请按照以下标准内容填写：

### 3.1 权限审核对照表

```
1. 权限：POST_NOTIFICATIONS (android.permission.POST_NOTIFICATIONS)
   - 申请用途：当用户为待办事项设置了到期时间或提醒闹钟时，应用需要在指定时刻向用户弹出系统通知横幅。
   - 弹窗时机：用户在任务详情面板主动点击设置提醒时刻并确认保存后，或进入设置页查看提醒指南时请求。
   - 不滥用承诺：仅发送与用户设定的待办事项直接相关的定时提醒，绝不发送广告、营销或无关推送。

2. 权限：SCHEDULE_EXACT_ALARM (android.permission.SCHEDULE_EXACT_ALARM)
   - 申请用途：待办管理工具核心业务依赖准时提醒，应用需通过 Android AlarmManager 在用户设定的精确分钟触发通知。
   - 合规保障：应用坚决不申请任何需要白名单特殊豁免的 USE_EXACT_ALARM 权限；严格遵循 Google Play 2023+ 关于待办与闹钟应用的 SCHEDULE_EXACT_ALARM 标准合规路径。

3. 权限：RECEIVE_BOOT_COMPLETED (android.permission.RECEIVE_BOOT_COMPLETED)
   - 申请用途：设备重新启动后，系统底层的定时排期会被清空。本应用仅在开机广播触发时读取本地存储，将尚未到期的有效待办重新注册到系统定时器中。
   - 行为边界：排期完成后立即释放广播接收器，绝不以此驻留后台常驻进程，不拉起任何关联流氓服务。

4. 权限：INTERNET (android.permission.INTERNET)
   - 申请用途：仅用于用户主动配置大语言模型 API Key 并触发 AI 分类、分组或目标拆解时直连用户指定的官方服务器。
   - 行为边界：所有普通待办的新建、编辑、删除与存储在无网络环境下 100% 正常运行。

5. 权限：VIBRATE (android.permission.VIBRATE)
   - 申请用途：提醒到期时的震动提醒，以及长按拖拽任务卡片时的轻微触觉反馈。
```
