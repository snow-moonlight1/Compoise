3. 开始先看 `git status`、AGENTS、HANDOFF。审查时是 `main / 9c622fd` 加已有未提交 R1–R5/S1 修复和文档，**禁止 reset 或覆盖其他人的改动**。当前没有远端，不创建分支、不推送或发布；提交仅遵循接手时用户授权与仓库规则。

### OS05 — 损坏启动不能覆盖原数据

- 状态：**已完成（2026-09-23）**。Store 启动对本机键标记缺失/正常/归一化/损坏；损坏或部分记录无法解析时不写回任一本机数据键，避免依赖关系误修覆盖。主界面前显示恢复页，可保存包含原始值的独立恢复副本（可能含凭据，非普通备份），或二次确认后丢弃损坏值并以可解析数据继续；取消和重启均保留原值。错误 UI 只列类别，不显示内容。OS-R01 修前失败、修后通过；专项 7/7 覆盖截断、错误顶层/primitive、局部坏记录、多次重启、取消、显式处置、正常新装和可迁移记录；默认全量 378/378、analyze 0 issues。保存失败及多键写入的可恢复提交留 OS06，未宣称掉电原子性或完成双端实机验收。
